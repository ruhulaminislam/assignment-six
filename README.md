# 🏋️ FitLog — Workout Library

FitLog is a modern and responsive workout library that helps users explore exercises, view detailed workout information, save favorite workouts, and create a personalized workout plan.

## ✨ Key Features

### 🏋️ Workout Library

Browse a collection of workouts with useful information such as:

* Equipment
* Duration
* Calories
* Rating

### 📋 Workout Details

View detailed information about each workout, including:

* Workout instructions
* Equipment
* Duration
* Calories
* Rating

### 📅 My Plan

Add workouts to a personalized workout plan and manage selected exercises in one place.

### ❤️ Save Workouts

Save favorite workouts and access them easily from the **Saved** section.

### 🔃 Sorting

Sort workouts based on:

* Duration
* Calories
* Rating

### 📱 Responsive Design

The application provides a responsive interface for:

* 📱 Mobile
* 💻 Tablet
* 🖥️ Desktop

## 📦 Dependencies

Main project dependencies include:

* Next.js

* React Toastify

## 🚀 Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/ruhulaminislam/assignment-six.git
```

### 2. Navigate to the Project

```bash
cd assignment-six
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:3000
```
